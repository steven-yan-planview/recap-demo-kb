# Data Platform Knowledge Base

Engineering knowledge base for the Data Platform team. Notes are generated and maintained by [RECAP](https://github.com/steven-yan-planview/RECAP) — an automated sprint knowledge extraction agent — and curated by the team.

## Structure

```
memory/
  architecture/    — System design and pipeline decisions
  storage/         — Snowflake, data store patterns
  security/        — Auth, access control, RLS
  api/             — API design, rate limiting, contracts
  onboarding/      — New engineer guides
  index/           — KB conventions and templates
```

## Contributing

RECAP opens PRs automatically after each sprint. Engineers review and merge.
Manual additions follow the conventions in `memory/index/Knowledge Base Conventions.md`.
